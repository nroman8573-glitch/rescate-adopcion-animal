# \# Análisis de requerimientos: Sistema de Control de Rescate y Adopción Animal

# 

# \## 1. Actores principales

# \- \*\*Ciudadano/Reportante:\*\* informa sobre un animal que necesita rescate.

# \- \*\*Voluntario/Veterinario:\*\* atiende los casos asignados y actualiza su estado.

# \- \*\*Administrador del Refugio:\*\* supervisa casos, asigna responsables y gestiona adopciones.

# 

# \## 2. Requerimientos funcionales

# \- RF1: Crear un caso de rescate con datos del animal y ubicación.

# \- RF2: Categorizar la especie (perro, gato, fauna silvestre).

# \- RF3: Asignar un voluntario o veterinario a un caso.

# \- RF4: Cambiar el estado del caso (Rescatado, En Tratamiento, En Adopción, Adoptado).

# \- RF5: Notificar automáticamente a los voluntarios cuando ingresa un nuevo rescate.

# \- RF6: Consultar el historial de un caso.

# 

# \## 3. Requerimientos no funcionales

# \- RNF1 Escalabilidad: permitir agregar nuevas especies sin modificar el código existente.

# \- RNF2 Mantenibilidad: diseño modular siguiendo principios SOLID.

# \- RNF3 Trazabilidad de versiones: control de cambios con Git bajo el modelo Gitflow.

# \- RNF4 Usabilidad: interfaz sencilla para ciudadanos y voluntarios.
